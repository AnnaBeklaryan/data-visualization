# Data Visualization Project

This project analyzes the Google Play Store Apps dataset as part of a data visualization course project.

Dataset source:  
https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Project Contents

- **Exploratory Data Analysis (EDA):** initial exploration of the dataset, including structure, missing values, distributions, outliers, and early visualizations.
- **Story & Insights:** a more focused analysis using interactive Plotly visualizations to identify the main patterns in the data and prepare for the final dashboard.

## Main Focus

The project explores app categories, popularity, ratings, and pricing in order to better understand the structure of the Google Play Store and support the design of an interactive dashboard.
